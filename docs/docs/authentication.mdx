# Authentication

Basic image browsing is available without authentication. User-specific features like favorites, albums, and reports require an API key or a JWT token.

## Authentication Methods

The API supports two authentication methods:

### API Key

Generate an API key from your dashboard and include it in the `X-Api-Key` header:

export const ApiKeyExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl -H "X-Api-Key: YOUR_API_KEY" ${baseUrl}/users/me/albums`}</CodeBlock>;
};

<ApiKeyExample />

API keys are the recommended method for programmatic access. You can list and revoke your keys via the `/auth/api-keys` endpoints with either method. Creating a key or changing its description/expiration requires a website session (JWT) – an API key cannot mint new keys. Likewise, changing user roles or bans and deleting files through the storage diff require a website session, even for administrators (`403` with an API key). A leaked key therefore cannot be used to persist access: revoking it ends it.

Requests with an invalid, expired or revoked key are treated as anonymous (endpoints that require authentication answer `401`).

### JWT Token (Discord OAuth2)

For browser-based flows, authenticate via Discord OAuth2:

1. Redirect the user to the Discord OAuth2 authorization URL.
2. The user authorizes the application.
3. Discord redirects back with a `code` parameter.
4. Exchange the code for a JWT token via `POST /auth/discord`.

Always send a random, single-use `state` parameter with the authorization request and verify it in the callback
before exchanging the code (login-CSRF protection). Tokens are valid for 7 days by default; role changes and bans
take effect immediately, also for tokens issued earlier.

Include the JWT in the `Authorization` header:

export const JwtExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl -H "Authorization: Bearer YOUR_JWT_TOKEN" ${baseUrl}/users/me/albums`}</CodeBlock>;
};

## Getting an API Key

export const FrontendLink = () => {
  const url = useFrontendUrl();
  return <a href={url}>{url.replace(/^https?:\/\//, '')}</a>;
};

1. Visit <FrontendLink /> and log in with your Discord account.
2. Navigate to your dashboard.
3. Generate an API key and store it securely -- the full key is only shown once.
